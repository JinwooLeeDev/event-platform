Busan Play 1-B 사전 분석 및 구현 계획 (2026-11-20)

브랜치: feat/다국어지원. 시작 시 미커밋 변경 없음. 브랜치 변경·커밋·푸시 금지.

1-A 검증: LocaleInfrastructureTest 10개, LocaleFlowTest 28개 모두 통과.
MessageSource UTF-8/한국어 fallback, 지원 Locale 제한, HttpOnly/SameSite 언어 쿠키,
최초 언어 모달, 헤더 UI, preferredLocale 가입 저장/로그인 동기화/로그아웃 보존,
CSRF 및 안전한 복귀 URL이 기존 코드에 존재한다. 중복 시스템을 만들지 않는다.
확장 필요: LocaleViewAdvice는 common 22개만 전달한다. 전체 메시지 모델과 안전한 JS 전달을 확장한다.

조사 범위: Mustache 80개, 정적 JS 10개. UI 조사 1294개 한국어 포함 줄 중
HTML UI/속성 849개, JS 후보 232개, 주석 207개, CSS/내부 문구 6개.
서버 후보 104개 Java 파일의 634개 줄: 예외 266, 응답 35, 표시/포맷 114, 검토 219.
기계 집계는 고유 번역 문구 수가 아니다. 상세 파일/줄은 build/i18n1b/*-inventory.json에 기록한다.

포함: 정적 텍스트/접근성/placeholder, JS 사용자 메시지, 오류/검증 표시, Enum 표시.
제외: 행사 제목/소개/설명, 기업/회원 이름, 카테고리 DB 이름, 리뷰, 공지/채팅 본문,
자유 형식 반려 사유, 개발 로그, 내부 enum/URL/CSS/폼 필드/저장 값, 외부 API 원문.

구현 단위
1. 기존 messages 4개 파일을 확장. 도메인별 키 및 공통 문구 재사용. 원문/키/출처 목록을 보존.
2. LocaleMessages/LocaleViewAdvice 재사용. Mustache는 HTML escape된 i18n 모델을 참조한다.
3. 동일 MessageSource에서 JS 메시지 JSON을 직렬화하고 script 종료/따옴표/개행을 안전하게 전달한다.
   별도 JSON 번역 저장소를 운영하지 않는다. 기존 이벤트/API는 유지한다.
4. 정적 텍스트/inline JS/static JS를 기능별 변환하고 문법·필드·URL·CSS를 검증한다.
5. 예외 처리와 명시적 표시 위치에서만 서버 문자열을 번역한다. 임의 객체/DB 문자열을 재귀 번역하지 않는다.
6. Enum 저장 코드는 유지하고 표시 getter/모델만 공통 매핑으로 번역한다.
7. 한국어 문자열로 계산하는 관리자 색상은 원문 기준을 보존한다.
   WebSocket 공통 브로드캐스트/저장된 시스템 문장은 쓰기 시 번역하지 않고 수신/표시 시 번역한다.
8. 키 일치/중복/빈 값/자리표시자/HTML/남은 한국어/JS 문법 및 4개 언어 실제 화면을 검증한다.
9. 관련 테스트를 우선 실행하고 전체 빌드·회귀 결과와 기존 실패를 구분한다.

날짜/숫자: 표시 Locale만 검토한다. 통화 KRW, 숫자 계산, DB 날짜/타임존 및 기간 판정은 변경하지 않는다.
Gemini 및 번역 DB 테이블/서비스는 구현하지 않는다. 동적 번역 준비 방향만 최종 보고한다.
